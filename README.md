# AMR — Architecture & Interiors

بورتفوليو عمرو الخطيب: صفحة واحدة تضم التعريف، فهرس المشاريع، الصور، خمسة أفلام تتحرك مع السكرول، و24 لوحة شوب دروينغ بالأبيض والأسود. صور الريندر تفتح بالحجم الكامل عند الضغط عليها.

## الموقع

عنوان GitHub Pages المخصص لهذا المستودع بعد تفعيل النشر:

https://amralkhatibamr-stack.github.io/portfolio/

ملفات الموقع المنشورة موجودة في `public/`. لا يحتاج الزائر لتثبيت أي برنامج أو تسجيل دخول.

## تعديل الموقع لاحقًا

| المطلوب | الملف |
| --- | --- |
| الاسم، التعريف، التواصل، ترتيب المشاريع والنصوص | `public/index.html` |
| الألوان والخلفيات والخطوط والمسافات | `public/styles.css` |
| الصورة الشخصية | `public/media/amr-profile.webp` |
| صور الريندر والفيديوهات والمخططات | `public/media/` |
| سرعة ومسافة السكرول لكل فيلم | `data-pixels-per-second` في `public/index.html` |
| سلوك الفيديوهات | `public/scroll-films.js` |
| عرض الصور بالحجم الكامل | `public/render-viewer.js` |
| تكبير المخططات داخل الصفحة | `public/drawing-layout.js` |

يمكن تعديل الملفات من GitHub أو من نسخة محلية، ثم حفظ التغييرات في فرع `main`. إجراء **Publish portfolio** يبني وينشر النسخة تلقائيًا. انتظر نجاحه في تبويب **Actions** قبل مشاركة التعديل.

### تغيير الصورة الشخصية

استبدل `public/media/amr-profile.webp` بصورة WebP جديدة. إذا كانت بصيغة أخرى، ارفعها إلى `public/media/` وعدّل `src` للصورة ذات `id="amr-portrait"` في `public/index.html`. حدّث `width` و`height` لنسب الصورة الجديدة. تغيير الصورة يتم من ملفات المستودع؛ هذه النسخة الثابتة لا تتضمن لوحة رفع عامة أو خادمًا لتخزين الصور.

### الحفاظ على الصور والفيديوهات

اترك المسارات نسبية مثل `media/example.webp`، دون شرطة `/` في البداية، لكي تعمل تحت `/portfolio/`. روابط الصور الكاملة تشير إلى نسخ بأبعاد المصدر الأصلية. لا تستبدلها بالصور المصغرة. الفيديوهات ملفات MP4 فعلية وتظل صامتة؛ الرجوع بالسكرول يرجع زمن الفيلم.

## معاينة محلية اختيارية

ثبّت Node.js 24 أو أحدث، ثم من هذا المجلد:

```sh
node tools/preview.mjs
```

افتح العنوان الذي يظهر. المعاينة تستخدم `/portfolio/` لاختبار نفس مسار GitHub Pages وتدعم طلبات أجزاء الفيديو. لا تحتاج إلى `npm install` لأن المشروع لا يعتمد على حزم خارجية.

```sh
node tools/check-site.mjs
node build.mjs
```

المجلد `dist/` هو ناتج النشر، لا تعدّل داخله.

## مصادر التوليد الاختيارية

`tools/generate-site.py` و`source/assets.json` و`source/videos.json` تحفظ طريقة توليد الصفحة. تشغيل `python tools/generate-site.py` يعيد كتابة `public/index.html` و`content.json`؛ إذا عدّلت HTML مباشرة لا تشغّل المولّد دون نقل تعديلاتك إليه. ملف `content.json` فهرس للمحتوى، وتعديله وحده لا يغيّر الصفحة. البناء والنشر العاديان يستخدمان `public/` مباشرة.

## إعداد الاستضافة

من **Settings → Pages → Build and deployment** اختَر **GitHub Actions**. سير النشر موجود في `.github/workflows/pages.yml`. الموقع عام، ولا يتطلب وصولًا إلى الاستضافة السابقة أو ملفات الجهاز الأصلي. تُنشر ملفات `public/` فقط؛ أدوات التطوير وبيانات التوليد تبقى في المستودع.
